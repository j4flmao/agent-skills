# Role-Based Skill Map (Loadouts)

Depending on the Agent's assigned role (or your learning path), focus on these specific directories:

### 👑 The Chief Technology Officer (CTO)
*Focus: High-level architecture, system resilience, and team productivity.*
- `skills/architecture/system-design/` (Microservices, DDD)
- `skills/architecture/databases/` (Scaling, CAP Theorem)
- `skills/devops/ci-cd/` (GitOps, Automation)

### 🚀 The Principal DevOps / Platform Engineer
*Focus: Infrastructure automation, monitoring, and deployments.*
- `skills/devops/orchestration/` (Kubernetes, Docker Internals)
- `skills/devops/iac/` (Terraform, Ansible)
- `skills/devops/observability/` (OpenTelemetry, Prometheus)

### 🧠 The Low-Level / Hardcore Systems Engineer
*Focus: Microseconds, memory management, and kernel bypassing.*
- `skills/niche/hft/` (DPDK, Ring Buffers)
- `skills/niche/low-level/` (eBPF, LLVM)

### 📊 The Data Engineer
*Focus: Big data pipelines and streaming.*
- `skills/data/data-engineering/` (Kafka, Data Lakes, Spark)

### 🎨 The Frontend & Client Architect
*Focus: User experience, UI performance, and device engines.*
- `skills/frontend/advanced-architecture/` (Micro-FE, RSC)
- `skills/mobile/cross-platform/` (Flutter, React Native)
